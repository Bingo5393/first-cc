# 微信 3.9.x 直装指南（当前系统，不用虚拟机）

目标：在你**当前这台电脑**上，把微信从 4.x 换成 3.9.x，跑「朋友圈转发助手」的 WeChatFerry 部分。

> 为什么换版本：WeChatFerry 只支持微信 3.9.x，而你现在的微信是 4.x，两者不能共存。
> 代价：这台电脑的 PC 微信日常改用手机，营销号用 3.9.x。

---

## 第 1 步：备份聊天记录（可选但建议）

- 微信 PC 聊天记录默认在 `C:\Users\MAC\Documents\WeChat Files\`
- 如果里面有只在电脑上、手机上没有的重要文件/记录，先手动拷出来
- 手机微信正常登录的话，聊天记录手机上都有，电脑卸载不丢手机数据

---

## 第 2 步：下载微信 3.9.12.56 安装包（用浏览器）

`wcferry 39.6.0.0` 精确对应**微信 3.9.12.56**（以 `spy.dll` 的 `ProductVersion=3.9.12.56` 字段为准）。

1. 官方源：腾讯软件中心 https://pc.qq.com 搜「微信」历史版本，找 **3.9.12.56**
2. 备用源：https://github.com/tom-snow/wechat-windows-versions 的 Releases
   （该仓库只有相邻的 3.9.12.55 / 3.9.12.57，小版本差异通常也能被 wcferry 兼容，可先试）
3. 下载 `WeChatSetup-3.9.12.56.exe`，存到 `F:\iso\`（约 150 MB）
4. （可选）核对 SHA256 与仓库记录一致

> ⚠️ 装完必须关闭自动更新，否则微信会悄悄升回 4.x 导致 hook 失效。
> ⚠️ 微信 3.9.x 登录时可能弹「版本过低」提示，见「常见问题」第 4 条。

---

## 第 3 步：卸载微信 4.x

- 设置 → 应用 → 已安装的应用 → 找到「微信」→ 卸载
- 卸载时「保留聊天记录」随意（3.9.x 大概率读不了 4.x 的本地记录，建议不留）

---

## 第 4 步：装微信 3.9.x + 关自动更新 + 登录

用脚本一键完成（装微信 + 引导关更新 + 装 Python 依赖）：

```powershell
# 以管理员身份运行 PowerShell
powershell -ExecutionPolicy Bypass -File E:\first-cc\vm-setup\setup_wechat.ps1 -WeChatInstaller "F:\iso\WeChatSetup-3.9.12.56.exe"
```

脚本会：
1. 检测当前微信版本（4.x 会提示先卸载）
2. 静默安装微信 3.9.x
3. 引导你手动：扫码登录营销号 → 关闭「有更新时自动升级」
4. 自动装 Python 依赖（pywinauto / pywin32 等）
5. 验证 wcferry 环境

也可以纯手动（不用脚本）：双击微信安装包 → 登录 → 设置里关「有更新时自动升级」。

### 关闭自动更新（关键，务必做）

1. 微信左下角「设置」→「通用设置」→ **取消勾选「有更新时自动升级」**
2. 进阶双保险：把微信更新域名加入 hosts 屏蔽（可选，一般 GUI 取消就够）：

```
# C:\Windows\System32\drivers\etc\hosts  末尾加：
127.0.0.1 dldir1.qq.com
127.0.0.1 dldir1v6.qq.com
```

> 注意：屏蔽 dldir 域名可能影响微信内下载图片/文件，一般不建议，先只用 GUI 取消勾选即可。

---

## 第 5 步：真机校准

装好后回到「朋友圈转发助手」目录：

```bash
# 1. dump 朋友圈消息原始字段（校准 type/sender/多图/XML 解析）
python tools/dump_pyq.py --wait 8

# 2. 校准发圈坐标（生成 publish_coords）
python tools/calibrate_coords.py
```

把 `dump_pyq` 的结果发回来，我据此精确化 `parser.py` 的解析逻辑；`calibrate_coords` 输出的坐标回填 `config.yaml`。

---

## 常见问题

- **装完微信打不开 / 报错**：确认已彻底卸载 4.x（两个版本残留会冲突），再重装 3.9.x。
- **微信自动升回 4.x**：说明「自动升级」没关干净，回第 4 步重新确认，或加 hosts 屏蔽。
- **登录不上 / 扫码没反应**：检查网络，或换个时间段（微信风控偶尔会限）。
- **登录时弹「版本过低，请升级」**：腾讯对 3.x 老版本的服务端限制，是当前 WeChatFerry 方案最大的不确定风险。
  本目录里的 `启动微信.bat` / `微信兼容.reg` 是上次尝试的「兼容层绕过」（`ARM64WOWONAMD64`），**效果未经实测证实**，装好后先直接双击微信试登录；被拦再看能否用这两个文件绕过，不行则此方案需要重新评估。
