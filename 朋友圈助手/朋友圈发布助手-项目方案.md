# 微信朋友圈自动发布助手 — 项目方案

> 记录日期：2026-09-06

## 一、目标

做一个能在微信上发朋友圈的应用，核心是「编辑好的文案」，最终实现（半）自动发圈。

## 二、关键决策

| 维度 | 决定 |
|------|------|
| 运行平台 | 安卓手机（微信运行在安卓手机上） |
| 自动化程度 | **先助手后自动**：先做安全的文案助手，再叠加自动化 |
| 应用形态 | Electron 桌面应用（Windows PC），复用现有 JS/Electron 技术栈 |
| 自动化后端 | Python + `uiautomator2` |
| 手机连接 | ADB（WiFi 无线优先，USB 兜底） |

## 三、架构

```
┌─────────────────────────────┐
│  Electron 桌面应用 (PC)      │
│  ├─ 文案库（编辑/模板/历史） │
│  ├─ [复制到手机剪贴板] 按钮  │  ← 第一阶段（安全）
│  └─ [自动发布] 按钮          │  ← 第二阶段（自动化）
└──────────────┬──────────────┘
               │ ADB（USB / WiFi）
               ▼
        ┌─────────────┐
        │  安卓手机    │
        │  微信 → 朋友圈│
        └─────────────┘
```

## 四、分阶段路线

### 第一阶段 —— 文案助手（零风险，先独立产生价值）
- 文案库：新建 / 编辑 / 分类 / 标签 / 搜索 / 历史记录，本地保存
- 内置常用营销文案模板
- 一键「复制到手机剪贴板」（走 ADB），用户在微信里手动长按粘贴发布
- 图片管理（文案之后再加）

### 第二阶段 —— 自动发布
- 手机开开发者模式 + 无线调试，ADB 连上
- 点「自动发布」→ 脚本自动打开微信朋友圈 → 粘贴文案 →（加图）→ 发布

## 五、前置准备

1. 一台安卓手机（微信正常登录）
2. 手机开启 **开发者选项 → USB 调试 / 无线调试**
3. 电脑安装 **ADB**

## 六、待确认事项

- [ ] 技术栈确认：Electron 桌面应用（而非手机浏览器网页版）
- [ ] 手机连接方式：USB 线 or WiFi 无线（默认 WiFi 优先、USB 兜底）
